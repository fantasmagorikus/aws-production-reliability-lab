# AWS Production Reliability Lab

A production-like AWS platform: ALB -> ECS Fargate -> RDS PostgreSQL across two
Availability Zones, with least-privilege IAM and network boundaries, CloudWatch
observability, deliberate failure drills, incident runbooks, and full
infrastructure as code (CloudFormation first, then Terraform).
